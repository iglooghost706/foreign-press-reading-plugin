# 外刊阅读插件

在网页上直接读英文外刊：**单击查词、双击入生词本、拖选翻译、悬停收藏句子**。
词典内置在扩展里，断网也能查词；只有长句/段落翻译需要联网。

- 版本 `0.1.0` · Manifest V3 · 适用 Chrome / Edge（Chromium 内核）
- 无账号、无服务器、无遥测：生词、笔记、设置全部存在本地 `chrome.storage.local`
- 纯原生 JS，无构建步骤、无依赖：改完源码在扩展页点「重新加载」即生效

---

## 1. 解决什么问题

读外刊时最常被打断的是三件事：**查词要切标签页、生词要手动抄、长句看不懂要整段丢进翻译器**。
这个插件把三件事压在同一页面上完成，读完一篇文章不用离开正文：

- 点一下就有释义，不用跳走（词典在本地，零等待）
- 双击就入库，释义和时间自动带上，回头能导出到 Anki 复习
- 拖选就翻译，自动区分「词组」和「整句」

还顺手解决一个副作用：读外刊时**点正文里的超链接会被带走**，一篇文章点两下就跑到别的网站去了。
「智能模式」让正文句子里的链接只查词、标题/卡片/导航照常跳转，需要真跳转时按住 `Alt` 点即可。

## 2. 功能

**四个手势是核心，其余都是围着它转的配套。** 下面按重要性分四层，越靠前越是日常会用的。

### 第一层｜核心手势（日常 90% 的用法）

| 手势 | 做什么 | 关键细节 |
| --- | --- | --- |
| **单击**单词 | 查词 | 本地词典 59,137 词，零等待、不联网；词典查不到时自动还原词形（`Analysts` → `analyst`）；浮层里可直接「加入生词本」 |
| **双击**单词 | 入生词本 | 自动存释义、原形、时间；已在库里提示「已在生词本」，不会重复入库 |
| **拖选**文字 | 翻译 | 按选中文本自动判定「词组翻译 / 句子翻译」；译文可一键复制，也可连译文一起收藏 |
| **悬停段落 → `☆`** | 收藏 | 段落或句子存入仓库，带上文章标题与来源域名 |

**释义浮层上的两个按钮**

| 按钮 | 出现时机 | 作用 |
| --- | --- | --- |
| `加入生词本` / `移出生词本` | 始终显示 | 一键入库或移出。已在库里时按钮变实心、文案改成「移出生词本」，再点就是移出 |
| `标记为重点词语` / `★ 取消重点标记` | **仅在已加入生词本后出现**，独占第二行 | 标为重点词，供「按重点」排序和「只考重点词」使用 |

- 入库后网页上会自动标记这个词：**蓝色虚线下划线**，鼠标移上去是 `help` 光标；它的变形也会一起标（`alloy` 入库后 `alloys` 同样被标出）
- 重点词更醒目：**红色虚线 + 加粗 + 淡红底**
- 点完按钮浮层自动收起，不会挡着继续读

### 第二层｜阅读体验（让正文不被挡住、不被带走）

**链接跳转三档**（工具坞 `智 / ⊘ / ↗`，点一下循环切换，悬停有说明）

| 档位 | 按钮 | 行为 |
| --- | --- | --- |
| 智能（默认） | `智` | 正文句子里的链接只查词、不跳走；标题、卡片、导航、页脚这类独立条目照常跳转 |
| 全部阻止 | `⊘` | 任何链接都不跳转，点哪儿都只查词——适合纯精读，不想被带走 |
| 全部允许 | `↗` | 完全恢复浏览器原生行为，点链接就跳；此时想查词要点非链接的文字 |

- 循环顺序：`智` → `⊘` → `↗` → `智`
- 无论当前哪一档，**按住 `Alt` 单击**一定跳转，不用改设置
- 设置页里也有同一个选项，与工具坞是同一份状态，改哪边都同步

**其他阅读辅助**

| 能力 | 说明 |
| --- | --- |
| 自动处理 Cookie 横幅 | 识别同意弹层后点「接受」，点不到就隐藏；正文出现后 30 秒内多次扫描，避免盖住开头 |
| 工具坞 | 右下角胶囊，四个按钮：`R` 总开关、`智/⊘/↗` 链接三档（见上）、`☆` 星标开关、`🔗` 收藏当前网址 |

### 第三层｜面板管理（点扩展图标或侧边栏打开，共五页）

| 页面 | 能做什么 |
| --- | --- |
| **生词本** | 搜索单词 / 释义；按时间、字母、重点排序（重点区内可再按时间 / 字母排）；`★` 标为重点词、删除单条；导出 Anki、导出 TXT、导入、清空 |
| **仓库** | 收藏的段落 / 句子 / 网址，按时间或来源排序；给每条收藏新建笔记；整体导出 |
| **笔记** | 不绑定收藏的独立笔记，可新建、重命名、删除、搜索 |
| **测试** | 从生词本随机抽题（数量可设），范围可选「不限 / 只考重点 / 不考重点」，逐条或一键显示释义 |
| **设置** | 见第四层 |

### 第四层｜设置项

- **翻译** —— 目标语言 8 种（简中 / 繁中 / 日 / 韩 / 法 / 德 / 西 / 俄）、引擎（自动 / Google / MyMemory）、MyMemory 邮箱（提高每日额度）、清除翻译缓存
- **阅读** —— 链接跳转三档、释义浮层显示在词上方还是下方、悬停星标开关
- **界面** —— 主题 4 套（白天 / 黑夜 / 赛博朋克 / 极简）、界面语言（中 / 英）、界面字号 10–20、小字说明开关

## 3. 安装方法

**前置**：Chrome 88+ / Edge 88+（Manifest V3 要求）。

1. 打开 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本目录（含 `manifest.json` 的那一层）
4. 列表出现「外刊阅读 0.1.0」即安装完成；点扩展图标可打开面板

> ⚠️ **Chrome 137 起，正式版已禁用命令行 `--load-extension` 加载扩展**，只能走上面的「加载已解压」。
> 这也是为什么本插件不做自动安装脚本。

**更新代码后**：在扩展页点该卡片上的 **重新加载**（圆形箭头），否则浏览器仍在跑内存里的旧代码。

**权限说明**（`manifest.json` 中声明，均可核对）：

| 权限 | 用途 |
| --- | --- |
| `storage` | 存生词本、仓库、笔记、设置（**实际使用**） |
| 主机权限 `translate.googleapis.com`、`api.mymemory.translated.net` | 翻译（长句/段落，以及词典未收录单词时的兜底） |
| 内容脚本 `<all_urls>` | 在网页上注入查词/翻译浮层（由清单自动注入，不读取、不上传页面内容） |
| `activeTab` / `scripting` | 清单中声明，当前版本未调用（浮层由内容脚本注入，面板只用 `storage` 与 `runtime`），后续版本可移除 |

## 4. 使用方法

**第一次用，走一遍这四步**

1. 打开任意英文新闻页（例如 `bbc.com`），右下角出现 `R` 胶囊即表示已生效
2. **单击**一个不认识的词 → 浮层出释义，试试点「加入生词本」
3. **双击**另一个词 → 右下角提示「已保存 · N」（N 为生词总数）
4. **拖选**一整句 → 看浮层标题自动变成「句子翻译」

**三个容易漏掉的操作**

- 正文里的链接想跳转：按住 `Alt` 再点，不用改设置
- 想标重点词：面板生词本里点词条右侧的 `☆`，之后可用「按重点」排序、也可以只考重点词
- 想临时关掉全部功能：工具坞 `R`，或面板顶部「● 开启」

**右下角工具坞**（四个按钮，从左到右）：

- `R` — 总开关，点一下关掉全部功能
- `智` / `⊘` / `↗` — 链接跳转三档循环切换（智能 / 全部阻止 / 全部允许）
- `☆` — 悬停段落星标的开关
- `🔗` — 收藏当前文章网址

**侧边栏**：面板页面同时注册为 Chrome 侧边栏（`side_panel`）。点工具栏的侧边栏按钮选「外刊阅读」，
或右键扩展图标 →「在侧边栏中打开」，就能一边读一边翻生词本，不用来回切标签页。

**复习与导出**

1. 点扩展图标 → 「生词本」→ **导出 Anki**，得到 `waikan-anki.tsv`，在 Anki 里「导入文件」直接可用
2. 或 **导出 TXT** 得到 `waikan-bank.txt`（`单词 ⇥ 原形 ⇥ 释义`），可给任意背单词软件
3. **导入** 支持 `.txt / .tsv`，按制表符、连续空格或 `n. ` 这类词性标记切分，已存在的词自动跳过。
   文件选择框里也列了 `.csv`，但解析器不按逗号切分，逗号分隔的 CSV 需先转成制表符分隔

## 5. 输入输出示例

### 5.1 单击查词

输入：在正文里单击 `resilience`

输出（浮层）：

```
resilience   内置词典
n. 弹回, 有弹力, 恢复力
[加入生词本]
```

### 5.2 词形还原

输入：单击 `Analysts`（词典里没有复数形式）

输出：自动还原为原形再查，浮层标注来源

```
Analysts   词典·原形还原
n. 分析者, 精神分析学家
原形 analyst
[加入生词本]
```

### 5.3 双击入生词本

输入：双击 `alloy`

输出：写入 `chrome.storage.local` 的 `wk_bank`，条目形如

```json
{
  "w": "alloy",
  "def": "n. 合金；vt. 将...铸成合金, 减低成色；vi. 合铸",
  "lemma": "",
  "ts": 1793452198601
}
```

### 5.4 拖选翻译

输入：拖选 `Researchers in Kyoto reported last month that a carefully engineered alloy retained its resilience even after ten thousand cycles of stress, an outcome`

输出（浮层标题会自动判定为「句子翻译」）：

```
句子翻译
京都的研究人员上个月报告说，即使经过一万次应力循环，精心设计的合金仍能保持其弹性，这是一个结果
[收藏句子] [已复制]
```

### 5.5 导出 Anki

输入：点「导出 Anki」（生词本里有 `alloy`、`resilience`）

输出文件 `waikan-anki.tsv`（UTF-8 BOM、CRLF，制表符分隔四列，空列留空）：

```tsv
Word	Definition	Lemma	Example
alloy	n. 合金；vt. 将...铸成合金, 减低成色；vi. 合铸		
Analysts	n. 分析者, 精神分析学家	analyst	
```

### 5.6 导出 TXT

输入：点「导出 TXT」

输出文件 `waikan-bank.txt`，每行 `单词 ⇥ 原形 ⇥ 释义`（无原形时只输出两列）：

```txt
alloy	n. 合金；vt. 将...铸成合金, 减低成色；vi. 合铸
Analysts	analyst	n. 分析者, 精神分析学家
```

### 5.7 导入

输入文件 `my-words.txt`：

```txt
tariff	关税
quota	n. 配额, 限额
```

输出：生词本新增 2 条，提示「已导入 2 词」；已存在的词不重复添加。

## 6. 目录结构

```
extension/
├── manifest.json        # MV3 清单：权限、内容脚本、侧边栏
├── background.js        # Service Worker：词典加载与查词、翻译引擎与缓存
├── content.js           # 页面内交互：查词浮层、双击入库、拖选翻译、工具坞
├── engine.js            # 纯逻辑（无 DOM）：词形还原、分句、分词
├── content.css          # 页面内浮层与工具坞样式
├── panel.html/.css/.js  # 面板：生词本 / 仓库 / 笔记 / 测试 / 设置
├── bridge.html/.js      # 桥接页：供桌面版侧栏读写同一份存储（不面向用户）
├── dict-ecdict.txt      # 主词典，59,137 条（基于 ECDICT 整理）
├── dict-lemmas.txt      # 词形映射表，38,031 条（不规则变化）
└── icon16/48/128.png
```

> 早期精选词表 `dict-builtin.txt`（1,298 条）已不参与查词，未纳入本仓库；当前查词只走 `dict-ecdict.txt` 与 `dict-lemmas.txt`。

## 7. 数据与隐私

- 所有数据只写本地 `chrome.storage.local`：`wk_prefs`（设置）、`wk_bank`（生词本）、`wk_repo`（仓库）、`wk_notes`（笔记）、`wk_tr_cache`（译文缓存）
- 只有**翻译**会发出网络请求（长句/段落，或词典未收录的单词），且只发送那段文字；查词完全离线
- 不采集页面内容、不注入统计脚本、不需要登录
- **卸载扩展会一并清空本地数据**，重要生词请先「导出 TXT」

## 8. 已知限制

- **首次拖选翻译较慢（约 6–8 秒）**：默认「自动」引擎先请求 Google 翻译，国内网络不可达时会等超时再回落 MyMemory；之后同一引擎进入冷却，第二次通常 1–2 秒。想彻底避开，在设置里把翻译引擎固定为 **MyMemory**。
- **MyMemory 有每日额度**（匿名 5,000 字符/天），在设置里填邮箱可提到 50,000 字符/天。
- **词形还原是规则实现**，对 `children`、`women` 这类不规则复数和 `sing`、`bring` 这类以 `-ing` 结尾的原形不生效，会保留原词。
- **词典释义偏短**，只保留新闻阅读常用义项；`[医] [计] [化]` 这类方括号表示专业领域。
- **智能模式是启发式判断**（看链接是否与正文同处一条行内流），非常规版式仍可能判错，此时按住 `Alt` 单击一定跳转，或在设置里改「全部允许」。
- **Cookie 横幅的自动处理同样是启发式**：靠文案 + 结构识别，iframe 内的弹层通常点不到，此时退化为直接隐藏；极少数站点可能误判，目前没有单独开关，可用工具坞 `R` 暂时关掉全部功能。
- 仅在 Chromium 内核验证（Chrome 156 实测通过）；Firefox 需另行适配。

## 9. 本地自测清单

无构建步骤，改完 `content.js` 等文件后点扩展「重新加载」，用任意英文新闻页验证：

1. 单击单词 → 浮层出现在词上方，释义非空
2. 双击同一个词 → 右下角提示「已保存 · N」，面板生词本出现该词
3. 拖选半句话 → 浮层标题为「词组翻译」；拖选完整句 → 标题为「句子翻译」
4. 正文句子里的链接单击 → 只查词不跳转；按住 `Alt` 单击 → 正常跳转
5. 卡片标题、导航、页脚链接单击 → 正常跳转（智能模式）
6. 工具坞 `R` 关掉功能 → 单击查词不再响应，页面恢复原生行为
